ANJU & PRASANTH WEDDING - DJANGO PROJECT

1. Open this folder in PyCharm.
2. Open the PyCharm Terminal.
3. Run:
   pip install -r requirements.txt
4. Run:
   python manage.py runserver
5. Open the browser address shown by PyCharm, usually:
   http://127.0.0.1:8000/

The website files are:
- wedding/templates/wedding/index.html
- wedding/static/wedding/style.css
- wedding/static/wedding/script.js
- wedding/static/wedding/images/
